Privacy Policy

Effective October 3, 2026

Chief Tasks (Google Cloud app name "Receipt API") is a private tool used only by its owner, Curt Fleenor.

What data it accesses

With the account owner's permission, the app accesses Google Tasks data (task lists and tasks) and any other Google data the owner explicitly authorizes, solely to help the account owner manage his own tasks and personal information.

How data is used and stored

Data is used only to provide this service to the account owner. It is stored only as needed for the service, on systems controlled by the owner, and is deleted when no longer needed.

Sharing

The app does not sell, rent, or share data with third parties, and does not use it for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
